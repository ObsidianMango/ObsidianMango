# Custom Luck / Whammy Big Board

Final asset-based build with a compact real raster sprite atlas, 18-space animated board, three-player banks, earned/passed spins, four-Whammy knockout, 26 mascot poses, randomized multi-shot gags, board editor, SFX, CRT mode, fast mode, fullscreen, and offline PWA caching.

Production build uses a chunked WebP sprite atlas for reliable GitHub publishing and browser-side reconstruction.
