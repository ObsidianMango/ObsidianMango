# Roadster Atlas

An interactive, mobile-friendly visual breakdown of a probable Gazelle / SSK-style kit roadster.

- Rotate, zoom and select 12 component groups.
- Separate assemblies, remove the roof, or expose the hidden systems.
- Take a guided tour or choose a camera preset.
- Read identification clues and linked sources.

The procedural model is illustrative, not measured. Exact builder, model year and donor drivetrain are unconfirmed. Hidden systems demonstrate a generic front-engine, rear-wheel-drive layout. The user's source photograph is not included in the public files.

Open `index.html` in a WebGL-capable browser. No build step or external runtime requests are needed. A local copy of Three.js r160 is included under its MIT license in `THREE-LICENSE.txt`.

Validated in Chromium at desktop and 390px-wide phone viewports: rendering, selection, exploded view, interior view, roof control and page overflow. Touch input supports one-finger rotation and two-finger zoom. Keyboard controls: arrows to orbit, +/- to zoom.
